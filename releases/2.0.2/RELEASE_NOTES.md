# NeuroMetBench 2.0.2 release notes

Version 2.0.2 repairs current method-result-claim traceability, exact cohort reconstruction, scenario-level simulation exposure, comparator execution provenance, data-access boundaries, figure missing-value semantics, accessibility-field text, release metadata, and complete-inventory verification.

The release preserves all frozen primary and secondary statistics, transport results, numerical results, adverse findings, non-admissions, technical failures, and historical provenance. The broad simulation remains a stylized Pearson/t/Fisher-z proxy rather than an exact simulation of the empirical Spearman/permutation/bootstrap engine. The reusable software API remains version 1.0.1.
